# Brand

The Ice Motion Director brand is built around ice. The mascot is an original character: a living ice cube made of voxel blocks, wearing a navy director beret and holding a clapperboard. Approved by the founder on 2026-10-19.

| File | Use |
|---|---|
| `mascot-hero.webp` | The approved main character, in its original scene: walking across a voxel film set on a floating ice island at dusk |
| `mascot-seated.webp` | The main character seated on a wooden director's chair, transparent background. The default cut-out for README, icons, docs and social |
| `../assets/icon.png`, `../assets/logo.png` | Plugin icon and logo for the Claude, Codex and Cursor listings (square, 512 px), made from the seated cut-out |
| `social-preview.html` | Source page of the GitHub social preview: the seated cut-out on a warm dusk stage, the name, the README tagline. Render command in its header comment |
| `../assets/readme/social-preview.png` | The GitHub social preview (1280x640, under 1 MB), rendered from `social-preview.html` with headless Chrome |

GitHub has no API for the social preview, so the founder uploads `assets/readme/social-preview.png` by hand: the repository's **Settings**, **General**, **Social preview**, **Edit**, **Upload an image**. Upload it again whenever the PNG changes.

Only this one character is the brand. Every new pose or scene starts from it and keeps its body, face, beret, clapperboard, colors and proportions.

## Palette

| Role | Color | Hex |
|---|---|---|
| Ice (primary) | Icy cyan | `#7FD8FF` |
| Frost (light) | Frost white | `#E8F8FF` |
| Beret (ink) | Deep navy | `#1E2A5A` |
| Accent | Warm coral | `#FF6F5E` |
| Dusk (support) | Peach | `#FFB38A` |

Warm coral against cold ice is the signature contrast. Keep the ice cold and the accent warm; never let the mascot sit on a cool blue background alone.

## Mascot rules

- Always voxel built: blocks and crisp pixel textures, never smooth 3D.
- The face stays simple: two square eyes, a small blocky smile, pink pixel cheeks.
- The beret and the clapperboard are the director marks; keep at least one in every pose.
- Gestures: open hands or holding the clapperboard. Never a single raised finger.
- No text inside mascot art; titles are set in code.

## Provenance

The mascot art was generated with ChatGPT image generation on the founder's account from prompts written for this project, then selected and compressed. It is an original character, not based on any game, studio or existing mascot.
