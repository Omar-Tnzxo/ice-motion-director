# Mixing several references

Read this when the user supplies two or more references, or one MOVES reference plus one LOOK reference. Never average references; assign functions and transform what you take.

## 1. Assign one function per reference

| Reference type | Supplies |
|---|---|
| MOVES (a video) | Pace, scene changes, camera, transitions, the one governing idea |
| LOOK (a site, brand, moodboard, image set) | Colors, fonts, materials, composition feel |

Write each assignment in `BRIEF.md` (References block, `function:`) and in the Treatment. Resolve conflicts in the Treatment, never by blending surface details. Mixed reference frames produce a mixed look: choose one master look, or map each look to a named job (for example one look for proof scenes, another for the hook), stated as illustration of the mapping, not a default.

Look priority: the user's LOOK reference, then the user's brand and motion brief, then a neutral palette labelled as a placeholder to replace. Brand rules outrank every reference.

## 2. Gene pool (for a deliberate recombination)

When the user wants something new built from several references (not a remake of one):

1. Decompose each reference into transferable genes. Each gene records: the observation (with time and evidence), the transferable principle, the protected specifics that must not be copied, and the transformation opportunity. Vague genes ("premium", "cinematic") are not genes.
2. Pair distant genes. Productive pairings: a mechanism with a material, a rhythm with a hierarchy, a constraint with a metaphor, a spatial rule with typography. One meaningful mutation beats a stack of distortions.
3. Mutate each adopted gene so it changes role, material, scale, timing, meaning or context. Operations: material swap, scale shift, time remap, spatialize, flatten, invert, role swap, metaphor shift, constraint transfer.
4. Optional wildcard: only to fill a named missing dimension (space, material, movement, hierarchy, transition, light, sequence, constraint), from a distant field, 1-3 at most, and stop searching once a concept passes.
5. Write three hypotheses that differ by mechanism: a coherent one, a tension one, a wildcard one. The pitch and the choice run through the ice-direction skill (separate critic).

Concept sentences describe a system, not a moodboard. Kill a concept if a reference is identifiable from its first frame, if it needs the references' own assets, or if it would fit any brief.

## 3. Creative distance audit

| Fails when | Passes when |
|---|---|
| One source dominates | At least two sources matter and none dominates |
| Scene order mirrors a source | Principles are transformed, not transplanted |
| A distinctive layout survives cosmetically | One thesis holds the film together |
| References sit as adjacent chunks ("A then B") | The film can be explained without naming the references |
| The wildcard is decoration | Every adopted gene has a job |

## 4. Mixing inside a remake

When one reference is the remake target and others are supporting: the target reference keeps the fidelity contract (`fidelity-contract.md`); supporting references contribute only the functions assigned in the brief. State in the Treatment which function comes from each, so a reviewer can check it.

## 5. Too few references

If the user supplied only one reference but the brief needs more grammar (for example a MOVES reference with no LOOK), ask for one more reference inside the stage 01 message, or (no answer, the user said not to ask, or the gap shows after 01) let the ice-direction skill research real, viewable examples, log the choice in `ice/DIRECTION.md` and report it. Every added reference must be opened and seen: a plausible title, a search snippet or a dead link is not evidence.
