## Rule for agents

Noncommercial use only. Before opening, copying or adapting any file in this folder for a film, the ice-film workflow must ask the user whether the film is for a noncommercial purpose (personal study, hobby, research, a charity, school or public body as the license defines) and record the answer in `ice/BRIEF.md`. If the use is commercial or unknown, do not use these files; the ice-film references and the domain skills cover the same ground from permissive sources. Commercial use of onetake requires the author's separate commercial license.

## What is here

| File | Source path | What it teaches |
|---|---|---|
| `onetake-skill.md` | `SKILL.md` | the full protocol: measure a reference, three concepts, beat sheet with rhythm and carry, footage or rebuilt UI, composition, render with shutter blur, sound, verify (renamed so loaders do not treat it as a skill) |
| `rhythm.md` | `references/rhythm.md` | why films read as slideshows (uniform cadence, beats that replace each other) and the carry score |
| `reference-deconstruction.md` | `references/reference-deconstruction.md` | reading a reference in numbers: stillness, bursts, cuts, the rule behind a style |
| `composition.md` | `references/composition.md` | one HTML file as a pure function of time, the hand path, an operated camera, deep zoom, render shutter |
| `motion-library.md` | `references/motion-library.md` | the move catalogue (enter, carry, contact, camera, fluid) and peak speeds |
| `motion.js` | `lib/motion.js` | the move library itself (`window.OM`), dependency-free, pure functions of time |
| `product-demo.md` | `references/product-demo.md` | product demos by UI replica, legibility arithmetic, narration, languages and time warps |
| `sound.md` | `references/sound.md` | a sound palette in one room, scoring from the composition's events, loudness per beat |
| `case-one-dot-15s.md` | `cases/one-dot-15s/README.md` | a worked case: one dot as the whole film, an operator camera, rejected versions and why |

Files that these documents mention but that are not copied here (scripts such as `render.py`, `probe.py`, `verify_promo.py`, the templates, galleries, looks, fonts and case films) are not part of this plugin. The `.md` files are English translations of the published Chinese originals; the first line of each file names its source and every change (translation included). Where a translation and the original disagree, the original wins.
