# Concept sources

Raw material for the concept round. Every list here is a deck of prompt cards: a card is a prompt, never an order. Left to choose, every film reaches for the same three moves, so before drawing, read the last fingerprints (`anti-sameness.md`) and set aside any card the recent films used. Never take a card because it is first in a list.

The concept raw material (narrative jobs, tension gaps, concept families, film kinds, opening and closing menus, metaphor patterns) is owned by the `ice-ideas` skill. This file keeps only what the pitch round adds on top.

## 9. Concept scoring (exposes trade-offs, never auto-picks)

Score each concept 1 to 5 on: message fit, clarity, brand or subject fit, transition potential, originality (distance from RQ-category conventions), asset feasibility, phone readability. Scores go to the critic with the concepts; the choice is a judgment with a written reason.
