# Mixing several references into one original direction

Never average references. Decompose each into transferable genes, connect distant genes, and mutate them until the result has one thesis and no source dominates.

## 1. When

- Two or more references in the brief.
- The user asks to "mix", "combine", or "something between A and B".
- Discovery is on: the direction lacks one dimension and a distant domain could supply it (wildcard, section 5).

## 2. Modes

| Mode | Gene pool |
|---|---|
| User curated | Only the user's references |
| Assisted discovery | The user's references plus researched references (`research.md`, RQ-refs) |
| Hybrid (default) | 2 to 6 primary references plus at most 3 wildcards from other disciplines |

## 3. Genes

For each reference, list genes. Each gene records four fields:

| Field | Content |
|---|---|
| Observation | What is visible or audible, located in time |
| Transferable principle | The rule behind it, stated without the reference's surface |
| Protected specifics | What may not be taken (logos, footage, exact layout, characters, palette of a third party) |
| Transformation opportunity | How it could change role, material, scale, timing or meaning here |

No vague genes: "premium", "cinematic" or "clean" are not genes.

State which function comes from which reference (illustration only: rhythm from one, type behavior from another, sound dramaturgy from a third). Resolve conflicts between references in the treatment, never by blending surfaces.

## 4. Mutation

Every adopted gene changes at least one of: role, material, scale, timing, meaning, context. Operations:

material swap, scale shift, time remap, spatialize, flatten, invert, role swap, metaphor shift, constraint transfer.

Productive pairings: a mechanism with a material, a rhythm with a hierarchy, a constraint with a metaphor, a spatial rule with typography. One meaningful mutation beats stacked distortions.

## 5. Wildcards

A wildcard fills one named missing dimension (spatial, material, movement, hierarchy, transition, light, sequence, constraint) from a distant domain (architecture, print, sport broadcast, science diagrams, craft, a game interface). Stop at 1 to 3. Never search for more after a concept passes. A wildcard that only decorates is removed.

## 6. Three hypotheses

Produce three mixes that differ by mechanism, not by color:

- **Coherent**: the genes reinforce one another.
- **Tension**: two genes pull against each other on purpose.
- **Wildcard**: the distant gene leads.

(When discovery is off, replace the wildcard hypothesis with a constraint route: one hard self-imposed rule shapes the film.)

Each hypothesis is one sentence that describes a system, not a moodboard. These become the three directions of the direction round (`pitch-round.md` B.4).

## 7. Creative distance audit

The critic fails a mix when any of these hold:

- one source dominates;
- the scene order mirrors a source;
- a distinctive layout survives cosmetically;
- references sit next to each other as adjacent chunks;
- the wildcard is decoration;
- it reads as "A plus B".

It passes when at least two sources matter, none dominates, the principles are transformed, there is one thesis, and the film can be explained without naming any reference.

Kill a mixed concept if a reference is identifiable from frame one, if it needs source assets, or if it would fit any brief.

The mix still passes the template distance and fingerprint rules of `anti-sameness.md`, measured against each reference as if it were a template.
